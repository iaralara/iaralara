## 💡 Sobre Mim

Sou desenvolvedora com sólida experiência na criação de **automações de processos corporativos (RPA)** e desenvolvimento de **aplicações web modernas**. Minha atuação é focada em resolver gargalos reais de negócios: eliminação de tarefas repetitivas, conciliação e auditoria financeira, integração com ERPs e portais bancários, e construção de interfaces intuitivas que entregam clareza operacional para lideranças.

- ⚙️ **Especialista em Automação (RPA):** Desenvolvimento de bots robustos com Python, Selenium, Pandas e APIs para automação bancária, fechamentos contábeis e conferência de inventário.
- 💻 **Desenvolvimento Fullstack:** Criação de aplicações web responsivas e seguras utilizando React 19, TypeScript, Tailwind CSS e Supabase com Row Level Security (RLS).
- 🔒 **Segurança & Boas Práticas:** Rigoroso padrão de conformidade e segurança da informação (LGPD, isolamento de credenciais via `.env`, tratamento preventivo de dados confidenciais e testes estruturados).
